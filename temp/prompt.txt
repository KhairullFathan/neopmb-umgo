saya ingin membuat aplikasi berbasis web untuk sistem pendaftaran mahasiswa baru universitas muhammadiyah gorontalo. saya menggunakan stack laravel + spatie (role permission) + stisla/stisla(view). sekarang saya belum untuk membuat antar muka saya ingin masuk terlebih dahulu ke dalama perancangan database. mari kita mulai dari user, untuk role ada superadmin, admin (panitia PMB), keuangan, akademik/kemahasiswaan, pimpinan, dan camaba. superadmin semua fitur. admin melakukan verifikasi berkas, mendaftarkan camaba dari dalam sistem, kelulusan, verifikasi pembayaran registrasi ulang. keuangan melihat statistik keuangan dari formulir sampai dengan verifikasi registrasi ulang. pimpinan melihat statistik pendaftar. dan camaba melakukan pendaftaran, upload berkas, mengikuti ujian, upload pembayaran. superadmin melalukan setup pmb, menambahkan data prodi, fakultas, semua fitur admin, keuangan, dan pimpinan. untuk admin, pimpinan saya ingin ada hak akses untuk mengakses prodi apa saja yang di izinkan, sehingga dapat di atur admin a hanya bisa verifikasi pada prodi a,b,dan c atau hanya a saja.
